# 官方來源匯入暫存

`manifest.json` 追蹤 109–115 年的 28 個年度科目包。`private/` 僅為本機取得的官方資產暫存，不是網站公開目錄，也不是已授權題庫。網站建置不可複製此目錄至公開輸出。

下載並校驗：`python scripts/ingest_sources.py --download`（需 Python 3 與 pypdf）。只核驗 PDF 標頭、大小、SHA-256 與頁數；不將題文交給 AI、不自動宣告答案已核對，也不宣告整卷收錄完成。

原 URL 與權利狀態保留於 manifest。公開網址只代表來源可取得，不能推定公開重製、改編或模型處理權。後續逐題解析、人工雙核、音訊、配分與授權仍有獨立門檻。

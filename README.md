## 💡 均一教育平台自學引擎 (Junyi Academy Engine)

1. **⚡ 步驟 0 破題思維 (Step 0 Thinking)**：
   - 教授「做題第一眼看哪裡」的直覺思維模式。例如：看到空格前有逗號 `(,)`，立刻排除關係代名詞 `that`；看到 `Unless` 子句，動詞從現代未絕不可加 `will`。
2. **🪜 雙階鷹架提示 (Scaffolding Hints)**：
   - **提示 1 (語法指標規律)**：提示時間副詞、句法成分與動詞形式。
   - **提示 2 (干擾項排除法則)**：指導如何運用詞性、主詞單複數或及物性排除誘答選項。
   - **精熟解析 (Syntactic Mastery)**：提供完整的句子剖析與中文對譯。
3. **🚨 42 項考場致命陷阱避雷雷達 (Fatal Traps Radar)**：
   - 橫跨國小基礎、國中會考、高中學測、統測與國際英檢常犯地雷，以 ❌ 錯誤例句、✔️ 標準正解與詳細診斷進行對比。
4. **🏅 12 枚核心素養徽章與 XP 經驗值**：
   - 從「拼讀領航員」到「終生自主雙語航海王」，學習者透過練習與精熟自動累積經驗值並解鎖徽章。

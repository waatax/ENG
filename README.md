## 🌟 專案全景與深度整合概述

本專案全面整合 **Arch 專案**、**Sixth 專案** 與 **JH 專案** 之所有英文教育頁面與資產，依據教育部 **108 課綱**、**學年** 與 **上下學期** 進行系統化體系重構，深度融合 **均一教育平台 (Junyi Academy)** 鷹架式微課與精熟學習理論，並經歷 **「七十個七次」（共 490 輪）** 極致迭代打磨而成。

平台涵蓋 **國小六年級 (小升初)**、**國中七至九年級 (會考衝刺)**、**高中與技術型高中 (學測統測先修)**，並銜接 **國際頂尖考制 (GEPT / TOEIC / SAT / GRE / GMAT / TOEFL)**。

```
Level 1: 國小階段 (Grade 6) 🎒
  ├── 6上 (6A)：作息時間與頻率副詞 (1-III-2) · 過去式故事冒險 (2-III-3) · 街道地圖問路指引 (1-III-4) · 健康飲食與身體照護 (2-III-4)
  └── 6下 (6B)：世界節慶與多元文化 (3-III-3) · 閱讀理解與拼讀導航 (3-III-4) · 未來計畫與夢想志向 (3-III-3) · 形容詞比較級與最高級 (2-III-6)

Level 2: 國中階段 (Grades 7–9) 🎓
  ├── 7上：句子骨架與現在簡單式 (JH-U1) · 名詞單複數與祈使句 (JH-U2) · KK音標與查字典指南
  ├── 7下：現在進行式與時間 (JH-U3) · 頻率副詞與情態助動詞 can (JH-U4) · 時空方位介系詞與地圖導航 (JH-U5)
  ├── 8上：過去簡單式與未來式 (JH-U6) · 過去進行式與連接詞 when/while (JH-U7) · 條件副詞子句 If/Unless (JH-U8)
  ├── 8下：形容詞比較級與動名詞不定詞 (JH-U9) · 連綴動詞與感官動詞最高級 (JH-U10)
  ├── 9上：現在完成式與被動語態 (JH-U11) · 授予動詞與使役動詞 (JH-U12) · 關代省略與介系詞搭配 (JH-U13)
  └── 9下：附加問句與間接問句 (JH-U14) · 多模態閱讀策略與推論 (JH-U15) · 跨文本圖表素養與會考衝刺 (JH-U16)

Level 3: 高中與技術型高中階段 (Grades 10–12) 🏛️
  ├── 10上：核心 1200 單字與詞性轉換 (S1) · 五大時態與被動語態先修 · 八大詞性骨架
  ├── 10下：複合句三大支柱 (S2) · 對等與從屬連接詞 · 名詞子句與副詞子句
  ├── 11上：非限定關係子句 (S3) · 關係副詞轉換 · 分詞構句簡化法則
  └── 11下：假設語氣時態倒退 (S4) · 否定副詞倒裝句 · 長篇職場與工程素養閱讀 (ESP)

Level 4: 歷屆大考與國際檢定 👑
  └── 109–115 國中會考 (CAP) · 108–115 高中學測 (GSAT) · 統測 (TVE) · GEPT · TOEIC · SAT · GRE · GMAT
```

## 🚀 六大核心功能特色

### 1. 🏫 108 課綱學年與學期地圖 (Curriculum 108 Navigator)
- **跨學年無縫切換**：可一鍵切換 6上、6下、7上、7下、8上、8下、9上、9下、10上、10下、11上、11下與國際考制。
- **對標課綱素養編碼**：每一單元均標註教育部官方指標（如 `1-III-2`, `2-III-3`, `3-III-4` 等）。
- **即時精熟狀態標記**：即時顯示 ⚪未開始、🟡練習中、🟢熟悉、⭐精熟。

### 2. 💡 均一教育平台 (Junyi Academy) 鷹架微課與思維破題
- **步驟 0 破題思維 (Step 0 Thinking)**：每單元提煉第一眼判斷法（如看到 *Look!* 鎖定進行式；看到 *since + 過去時間* 鎖定完成式）。
- **漸進式鷹架提示**：提供「提示 1（語法指標規律）」、「提示 2（干擾項排除技巧）」與「精熟解析（句法結構完整剖析）」。
- **考場致命陷阱 X 光機 (Fatal Traps Radar)**：針對進行式漏 *be*、頻率副詞位置搞混、*Although... but* 雙重連接詞、關代 *that* 前逗號禁忌等 40+ 個台灣學生高頻失分點深度診斷。
- **技能徽章與 XP 經驗值**：答題即時累積 XP，解鎖「拼讀領航員」、「語法偵探」、「句型建築師」、「會考全勝神將」等成就勳章。

### 3. 🎒 Sixth 專案完整移植 (國小六年級旗艦庫)
- **8 大單元高解析講義**（`eng-u1.md` 至 `eng-u8.md`）。
- **64 大考前筆記速記心訣**（`engNotes.js`）。
- **自然拼讀與情境對話語音館**（`englishAudioData.js`，包含短長母音對比、雙人生活會話）。
- **128 題課綱段考代表題庫**（`engQuestions.js`，附即時選項解析與精熟度結算）。

### 4. 🎓 JH 專案完整移植 (國中 7–9 年級會考衝刺館)
- **16 大會考單元綱要**（`english-1` 至 `english-16`）。
- **16 個語言生活情境案例**（`cases-language.js`，生活公告、租借對話、圖表閱讀）。
- **109–115 國中教育會考 (CAP) 官方大數據考點解析**。
- **16 份主題會考手冊與講義清單**。

### 5. 🏛️ Arch 專案完整移植 (高中/技高先修與學期複習)
- **5 大先修主題模組**：
  1. *五大基本時態與被動語態全圖解 (Basic Tenses & Passive)*
  2. *複合句與連接詞核心支柱 (Complex Sentences)*
  3. *八大詞性與詞綴轉換判讀 (Parts of Speech)*
  4. *國際音標 (IPA/KK) 與英語字典查詢指南 (Phonetics & Dictionary)*
  5. *108 課綱核心 1200 單字互動字卡庫 (Vocab 1200 Core Explorer)*
- **高中 4 個學期深度講義**（`englishS1Review` 至 `englishS4Review`）。

### 6. 🖨️ A4 考前 10 分鐘精華複習講義列印庫
- **標準 A4 列印格式**（`@page { size: A4; margin: 12mm 15mm; }`）。
- **官方講義專屬抬頭**（學校、班級、座號、姓名）。
- **考前 10 分鐘必備檢核清單 (Checklist)**（支援互動式勾選）。
- **名師考前速記公式大公開** 與 **考場避雷針**。

- 採用標準美國英語 (`en-US`) 原生語音合成引擎。
- 支援 **🔊 正常速度 (1.0x)** 與 **🐢 慢速精聽 (0.8x)** 雙模式切換。
- 全站單字、例句、對話均可一鍵點讀，無須額外安裝任何外掛。

```bash

node site/server.mjs

# 開啟瀏覽器造訪
http://127.0.0.1:4173
```

# English Quest 英語學習平台

English Quest 是以繁體中文說明英語知識點、提供分年級課程與自學練習的靜態網站。網站提供國小至高中主題課程，以及 TOEIC、SAT、GRE、GMAT 等考試方向的原創練習與官方資源入口。這些課程標籤供導航使用，不表示教育機構或考試主辦方認證。

## 閱讀與操作

- 閱讀設定可切換柔和、明亮、深色等配色，調整文字及介面大小；設定保存在此瀏覽器。
- 知識點頁優先呈現搜尋、觀念、例句與練習；延伸學習及語音功能可按需展開。
- 版面適配手機直式及桌面，支援鍵盤操作。正式無障礙合規等級尚未經完整稽核。

## 題庫的實際狀態

考試方向題庫共有 **20,000 筆資料，但只有 482 道不同題面**（以文章、題幹、選項完全相同判定）。練習時會排除完全重複的題目；篩選後若少於所選題數，會顯示實際可用數量。各考科不同題面數如下：

| 考科方向 | 資料筆數 | 不同題面 |
| --- | ---: | ---: |
| 高考方向 | 6,000 | 60 |
| 國中會考方向 | 1,000 | 183 |
| 高中學測方向 | 1,000 | 8 |
| TOEIC | 3,000 | 148 |
| SAT | 3,000 | 16 |
| GRE | 3,000 | 47 |
| GMAT | 3,000 | 20 |

另有 2,000 筆分層練習資料；這些數量只說明資料結構與題面差異，**不是教學品質或測驗效度的證明**。本站測驗回饋不能換算 CEFR、正式考試分數或證書等級。未逐題核實來源的練習題不標作官方歷屆真題。

## 本機預覽與檢查

需要 Node.js。執行 `node scripts/preview_listening.cjs`，再開啟 `http://localhost:8080`。執行 `node --test scripts/test*.mjs` 檢查主要互動及內容規則；執行 `node scripts/audit_learning_content.mjs` 產生 [內容結構審查結果](CONTENT-AUDIT-2026-10-04.json)。

## 2026-10-23 闖關模式：Duolingo 式全站改版

新增 [English Quest 闖關模式](https://waatax.github.io/ENG/quest/)，主站首頁最上方有入口。

- **規模**：把現有教材依程度排成一條學習路徑，共 9 段主線（Pre-A1 到 B2–C1）、82 個單元、363 個關卡。另有 8 條目標分支：會考、學測統測、技高職場、英檢與托福、TOEIC、SAT、GRE、GMAT，各分支都可以直接開始。
- **題目**：5,845 題由 79 個學年微課、2,000 題分層題庫、知識點、圖解文法、綜合章節與 1,000 張聯想字卡轉換而成。題型有選擇、聽力、排句、輸入、配對與互動故事（51 篇，涵蓋 Pre-A1 到 C1 全段落）。
- **遊戲機制**：XP、每日目標、連續天數與凍結卡、每日任務、寶石、成就、單元挑戰（3 顆心，通過得金冠）、跳級測驗與程度測驗。一般課程沒有愛心，答錯不會被鎖住；錯題會在課尾再出一次，並收進錯題本，依 1→3→7→14→30 天安排複習。
- **驗證**：196 項回歸測試與 17 項瀏覽器流程都已通過。題目由程式轉換並經檢核，尚未逐題經教師審定，也還沒有真人試用。XP 不代表正式程度。

## 2026-10-12 諧音聯想強化版＋500 組字根字族

新增 [500 組字根字族](https://waatax.github.io/ENG/roots/?v=keyword6)：150 組複合詞字族（board → blackboard、whiteboard、scoreboard）、70 組字首、60 組字尾、220 組拉丁希臘字根（commun → common、communicate、communication、communion），共 2,581 個成員字。每組有拆解、記憶提示與 MP3（點單字只播那個字），可遮住中文自我測驗並安排間隔複習。研究依據、與 Codex 複核的整合、多代理審稿、驗證與限制見 [本次紀錄](REVIEW-MNEMONIC-ROOTS-2026-10-12.md)。內容由 AI 編寫並經程式與審稿代理檢核，未經外部教師審定或學習成效實驗。

English Quest 是以繁體中文說明英語知識點、提供分年級課程與自學練習的靜態網站。網站提供國小至高中主題課程，以及 TOEIC、SAT、GRE、GMAT 等考試方向的原創練習與官方資源入口。這些課程標籤供導航使用，不表示教育機構或考試主辦方認證。

## 閱讀與操作

- 閱讀設定可切換柔和、明亮、深色等配色，調整文字及介面大小；設定保存在此瀏覽器。
- 知識點頁優先呈現搜尋、觀念、例句與練習；延伸學習及語音功能可按需展開。
- 版面適配手機直式及桌面，支援鍵盤操作。正式無障礙合規等級尚未經完整稽核。

## 題庫的實際狀態

考試方向題庫共有 **20,000 筆資料，但只有 482 道不同題面**（以文章、題幹、選項完全相同判定）。練習時會排除完全重複的題目；篩選後若少於所選題數，會顯示實際可用數量。各考科不同題面數如下：

| 考科方向 | 資料筆數 | 不同題面 |
| --- | ---: | ---: |
| 高考方向 | 6,000 | 60 |
| 國中會考方向 | 1,000 | 183 |
| 高中學測方向 | 1,000 | 8 |
| TOEIC | 3,000 | 148 |
| SAT | 3,000 | 16 |
| GRE | 3,000 | 47 |
| GMAT | 3,000 | 20 |

另有 2,000 筆分層練習資料；這些數量只說明資料結構與題面差異，**不是教學品質或測驗效度的證明**。本站測驗回饋不能換算 CEFR、正式考試分數或證書等級。未逐題核實來源的練習題不標作官方歷屆真題。

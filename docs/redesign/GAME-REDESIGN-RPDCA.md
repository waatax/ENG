# English Quest：依能力前進的遊戲化英語學習改版

版本：研究規劃 v1｜2026-10-23｜狀態：R0 完成，R1–R6 待執行

## 1. 核心決策

將網站從「大量教材與工具入口」改為「每天知道下一步的英語闖關旅程」。使用者先選目標、選擇是否做起點檢核，再進入短課、立即回饋、補強與跨日複習。保留現有完整教材作為隨時可開啟的學習手冊。

借鑑 Duolingo 的路徑、短課、單題互動、即時回饋與日常任務；使用 English Quest 自己的名稱、角色與視覺。成功指標是能獨立回答新情境、隔日仍能回想，以及願意持續學習。

優先順序：內容可用性 → 能力與先備關係 → 關卡閉環 → 首頁與路徑 → 獎勵 → 規模化。先完成 3 個單元、12 個節點的試點，再擴到其他程度。既有頁面仍可自由閱讀，進階使用者可檢核跳級。

本輪不預設學習者年齡、目前程度或主要考試。先以繁體中文、自學、手機優先、5／10／15 分鐘日目標設計；成人起步者可使用相同基礎能力線，不強迫顯示國小年級身分。

### 已讀代表教材與具體發現

- `#unit/g3-s1-u1`：包含 A–M 大小寫、問候、姓名、4 輪對話、閱讀與形成性題目。適合拆分；問候課不應同時強制背完 13 個字母。
- `#knowledge/be-sentences`：已有先備、規則、正反例、選擇題、自我介紹任務，可轉為 be 動詞小單元。
- `#knowledge/present-questions`：第三人稱、肯定、疑問、否定集中；需先建立 be 與一般動詞區別，再拆 do／does。
- `#chapter/jhs/j1`：同時涵蓋五大句型及四大時態，適合國中整合；不適合作為所有新手第一關。
- 既有遊戲的第一個重組句是 “Actions speak louder than words.”，聽句包含 “The teacher told us that water boils at 100°C.”，超過零基礎自我介紹所需負荷。
- 咖啡會話 `commute-daily-01` 有尺寸、少冰、加購、感應付款及取餐位置五輪；可拆成生活應用分支，不能直接拿完整長句測零基礎聽說。
- 字卡的既有品質過濾器只偵測少數已知句型模板，實測標記 13 張且有替代內容；其他未被標記的卡也不自動合格。原檔仍可見 “Students are encouraged to export questions…” 等可疑搭配，需列入語義審查候選。

### 目前工程限制

1. `duolingo_game.mjs` 的開放判斷只允許 J1，五個 stage 與題目寫死在 UI 狀態中；開啟會 reset。需建立資料驅動引擎，不能僅把限制改成全部允許。
2. 舊遊戲有 5 顆心，歸零進入重開畫面。新版將連錯導向支援，不中斷學習權限。
3. `junyi_engine.mjs` 以累積至少 4 次、答對率 85% 判定 mastered；目前紀錄不足以證明首次陌生題、跨日保留與遷移。新舊狀態不能直接當同一種精熟。
4. `learning_journey.mjs` 已有收藏、最近學習、自評 1／3／7／14 天複習；優先沿用其入口與舊資料，不重造孤立系統。
5. 診斷、會話、字卡、知識點、筆記及 Junyi 分開儲存；需定義共同能力紀錄與相容層。
6. GitHub Pages 工作流程發布 `dist/`；多個回歸測試同時要求 `site/dist/` 一致。新增程式須針對修改檔同步，避免整批發布未完成素材。
7. 工作區已有水彩聯想圖等未完成變更；本輪保留，後續不得誤納改版發布。

| 來源 | 支持的判斷 | 本站的設計決策 |

## 4. 程度與目標分成兩個軸

### 能力主線

下列是站內課程階段，不是測驗認證，也不以學齡限制入口。

| 階段 | 能做到的事 | 既有內容來源 | 進階證據 |
| --- | --- | --- | --- |
| S0 聲音與第一句 | 認字母、聽懂簡短招呼、說姓名 | G3–G5、自然拼讀、教室用語 | 不看完整示範完成問候；聲音辨識另測 |
| S1 日常基本表達 | 身分、喜好、時間、日常習慣與簡單問答 | be、do／does、G6–G7、基礎文法 | 不同人物與情境下獨立作答 |
| S2 生活溝通 | 過去經驗、計畫、比較、請求與短文理解 | G7–G9、J1–J7、生活會話 | 短文找證據、情境接話、延遲回想 |
| S3 篇章與職場應用 | 解釋理由、讀較長文章、處理郵件與流程 | G10–G11、被動／子句、高工章節 | 跨句理解、短段寫作及任務完成 |
| S4 學術與論證 | 分析主張、證據與假設，組織較完整表達 | 高中篇章、論證知識點、Academy | 新文章推理與有量表的產出 |

參考 CEFR 的能力描述建立內容標籤，但不在本輪制定 S0=A1 等一對一換算。原資料含 CEFR、年級、分數口號時，保留於來源記錄；新版對使用者的程度呈現改為「目前建議從哪裡學」。

### 目標分支

- 生活與旅遊：點餐、問路、改約、退換貨、澄清。
- 學校學習：依年級、課綱與會考／學測需求找主線節點。
- 技高與工作：指令、表格、操作說明、郵件、簡報。
- 學術與考試：GEPT、TOEIC、TOEFL、SAT、GRE、GMAT 各自的目標分支；考制細節在實作該分支前重新查官方規格。

TOEIC → SAT → GRE → GMAT 不設定為必經升級順序。選考試只影響主題與任務比例，不能自動表示語言能力。

### 起點檢核與推薦

首次三步：選目標 → 選每日時間 → 選「從基礎開始／做短檢核／自行選路徑」。檢核可略過，之後可重選。

初始假設：8 題篩查，最多補至 16 題；只用已審核、不同題面。每個欲判斷的能力至少 4 筆獨立證據，否則顯示「資料不足」。未測聽力、口說或寫作一律未知，不能用閱讀成績填補。

分技能的暫定分流：無提示首次答對 0–1／4 建議補先備；2／4 建議有提示起步；3–4／4 提供該能力的挑戰入口。這是推薦規則，不是能力量尺。選擇題通過只允許跳過相應辨識練習，不能跳過尚未檢核的口語產出。

推薦優先序：未完成課程 → 到期複習（每日最多先推 2 個短課）→ 連錯能力的補強 → 符合先備的新課 → 自選探索。沒有足夠合格題時顯示可用範圍，不補入重複題假裝檢核完成。

## 5. 一次課程的完整循環

一般短課規劃 3–6 分鐘、6–10 個可作答步驟；新手採較少步驟，長篇閱讀與產出可另開 8–12 分鐘任務。數值待試用調整。

1. 目標：用生活語言說「今天學會介紹你和朋友」。
2. 示範：1–2 個短例句，可聽可看，重點只突出一個。
3. 引導：配對、選擇、重組，有可展開的規則提示。
4. 獨立：撤除提示，使用不同句子；首次作答另存。
5. 應用：換人物、時間或溝通目的，說或寫一個新句。
6. 修復：答錯指出「哪個線索、為何、下一次怎麼想」，再安排替代題。
7. 結果：顯示完成內容、仍需練習的技能、下一步與複習日期。

題型需和能力對應：配對測辨識；重組測語序；短答測提取；聽音選圖或選意測聽辨／理解；故事分支測語用；證據定位測閱讀；角色接話與短文測產出。不能只換題目外觀就聲稱同時測到四技能。

文字輸入需支援空白、大小寫及標點規則；每題明定可接受變體，例如 I'm／I am。大小寫本身是目標時才計錯。語意正確但未列入的答案允許標記待核，不強制判定錯誤或發放精熟。

聽力出題前檢查可播放；失敗可重播、改成閱讀模式或略過。改成閱讀的題只增加閱讀練習紀錄。口說先用裝置示範＋自評；未接入有效評分時不顯示發音分數。繁中解釋與英文語音分開控制。

## 6. 遊戲機制與能力證據

| 機制 | 初始規則 | 防止失真 |
| --- | --- | --- |
| 路徑節點 | 未開始、進行中、已完成、待複習、已鞏固 | 每種狀態有文字與圖示，不只靠顏色 |
| XP | 首次完成課程 10、按期複習 5、單元挑戰 15 | 同一完成事件只記一次；同日刷同課不重領 |
| 連續學習 | 當地日期完成至少一個有效課程或複習 | 單純開頁、播放或重複提交不算；中斷不扣已學進度 |
| 每日任務 | 一關新課、一回到期複習，或使用者自選 | 到期池為空時改為回想任務，不虛構欠債 |
| 徽章 | 首次開口自評、首次按期複習、單元完成 | 徽章名稱描述行為，不聲稱通過正式級數 |
| 連錯支援 | 同技能連錯 2 次，主動提供示範／較簡單題 | 可繼續學習；不扣生命到無法作答 |
| 單元挑戰 | 首次陌生題＋情境任務 | 重複背答案不算獨立通過 |

**完成與鞏固分開。**

- 已完成：課程流程走完，錯題已看解析並再嘗試；自評產出顯示自評。
- 待鞏固：有獨立答題證據，但尚未跨日檢核。
- 已鞏固（站內暫定）：同技能至少 5 個不同題面之無提示首次作答、正確率至少 80%，至少一次延遲 24 小時後獨立回想，並通過一項不同情境任務。這些門檻是試點規則，需依學習資料調整。
- 輔助後答對、當堂重做、播放完成都保留，但不混入首次無提示分母。口說自評單列，不能替代客觀測試。

複習先採既有 1／3／7／14 天相對間隔；到期成功才前進，提前重練不提高階段，失敗回到 1 天。自評和客觀回想使用不同 evidenceType。每日任務依使用者本機日期計算，測試須涵蓋 Asia/Taipei 午夜與跨時區；目前舊 Junyi 使用 UTC 日期字串，遷移時不可照抄。

## 7. 整體介面與內容架構

主要導覽收斂為四個入口：「旅程／練習／教材／我的」。桌面固定側欄，手機底部導覽。

首頁上方：目前目標與階段、今日任務、主要「繼續學習」按鈕；中段為所在單元的 4–6 個節點與可展開的後續單元；下方提供補強及手冊。避免把 154 個入口同時攤開。

旅程地圖以生活場景命名，例如「認識新朋友」「我的一天」「城市任務」「說明你的想法」。可採圓形節點、清楚連線與輕量獎勵動畫；每個節點顯示目標、時間、狀態與先備。不熟先備的高階課仍可預覽，並清楚提供補強入口。

關卡畫面同時只有一個作答區；頂端有進度、退出／儲存，底部為檢查／繼續與回饋。未選答案不能送出；送出後鎖定該次作答，避免多次計分。退出可保留 session，不把未完成當已通關。

保留長篇說明的價值：題目旁「看懂這個觀念」展開短提示，再連回原教材對應段落。詞彙、音訊、聯想與字根都由目前關卡帶入，完整資源仍放在「教材」。

視覺規格待 R3 製作：繁中文字級至少 16px、主要觸控目標以 44px 為設計目標、清楚焦點、鍵盤可用；尊重減少動態設定，動畫／音效可關；選項和結果不只用紅綠。320、390、768、1280px 及文字放大 200% 檢查，不設定只能拖曳才能完成的題型。

## 8. 內容轉換與發布閘門

每個單元建立：穩定 ID、來源路由、來源版本、能力目標、先備 ID、站內難度、目標分支、關鍵詞、示範、練習題、答案變體、解析、常見錯誤、替代題、遷移任務、音訊與審核狀態。

狀態流程：inventory → adapted → editorial-reviewed → functional-verified → pilot-ready → released。只有 inventory 的頁面不顯示成可玩的正式關卡。

1. 整理原文與題目，保留 sourceRef；以 hash 偵測來源變更。
2. 按單一能力拆課，不以字數平均切割，不自動把 154 頁乘固定關數。
3. 逐題檢查英語自然度、中文意思、選項唯一性、難度、答案變體與解釋。
4. 同題不同 ID、改標點、換選項順序的變形不當新能力證據；建立 itemFamilyId。
5. 先備關係檢查不可循環、不可指向不存在的技能。
6. 發音、聽力內容需實際試聽；合成語音標明裝置語音，必要時保留可核對文字。
7. 發布試點前每題需有具名審查紀錄與結果；教師／學習者試用未進行時明確列待辦，不冒充專家審定。

起點檢核、練習、單元挑戰分開抽題池；題量不足就縮小試點範圍。官方原卷與原創題沿用既有來源分層，未核對權利的原卷不轉入遊戲素材。

## 9. 技術實作與舊資料遷移

第一階段沿用現有靜態網站與 ES modules；資料、純邏輯、畫面各自分離。新遊戲可先以獨立路由試行，通過驗收才切換首頁。

建議模組（待建立）：

- `quest_catalog.mjs`：單元、關卡、先備及既有路由映射。
- `quest_engine.mjs`：session 狀態、作答、提示、修復、結算；不依賴畫面。
- `quest_progress.mjs`：版本化事件、XP 去重、技能證據、遷移與匯出。
- `quest_scheduler.mjs`：起點建議、下一關與到期複習，時間可注入測試。
- `quest_view.mjs`／`quest.css`：題型呈現、鍵盤操作、手機路徑。
- `data/quests/`：經審查的教材轉換資料與題目。

事件最少欄位：schemaVersion、eventId、sessionId、questId、itemId、itemFamilyId、skillId、contentVersion、timestamp、localDate、attemptIndex、hintUsed、answerMode、result、evidenceType。紀錄應足夠重建學習結果；預設不保存個資、麥克風音檔或非必要自由文字。

遷移採新增版本與保留來源：

| 舊資料 | 新版映射 | 不可推論 |
| --- | --- | --- |
| 收藏／最近閱讀 | 教材收藏／最近開啟 | 不能直接標成關卡完成 |
| 自評回想日期 | 自評複習隊列 | 不能變成客觀測驗通過 |
| 已聽會話 | 已聽內容清單 | 不能變成口說通過 |
| Junyi XP／徽章 | 舊版成就區 | 不能直接換新版階段或重複發獎 |
| 既有 mastered | 舊版練習紀錄，可引導短檢核 | 不能假定已有跨日／遷移證據 |
| 筆記／訂正 | 原路由映射、可下載備份 | 不刪除、不重寫原內容 |

遷移流程：讀取並驗證舊資料 → 建立備份與版本標記 → 寫新 key → 驗證成功 → 保留舊 key。重做遷移應冪等；損壞資料逐項略過並提示。儲存失敗時保持本次可用、顯示未儲存狀態；沒有伺服器時不承諾跨裝置同步。

大型字卡與音訊按需求延後載入，首頁不為少量關卡一次下載全部 9,500 字。重做這一部分前量測現有首頁載入瀑布圖，不能只因檔案大小就宣稱目前效能不合格。

## 11. 驗收與成效指標

工程發布門檻：選定關卡來源 100% 可追溯；零致命流程錯誤；重載不丟已提交作答；同事件不重複計 XP；未測技能保持未知；舊資料可備份；每個失敗狀態有可繼續的操作。

試用先邀 5–8 位不同起點者做可用性測試，這個樣本只找流程問題，不推論學習效益。任務包括選起點、完成第一關、答錯後補強、退出續學、找到複習及教材。

| 指標 | 分母與量測方式 | 初始決策規則 |
| --- | --- | --- |
| 找到下一步 | 受試者是否在 60 秒內無協助開始合適任務 | 小樣本若反覆卡住，先修首頁導引 |
| 短課完成率 | 開始課程 session 中完成的比例；退出原因另記 | 先建立基準，不用總完課數掩蓋流失 |
| 首次獨立正確率 | 不同題面、未看提示的首次答案 | 持續低於 60% 查先備／題目；高於 95% 查是否太簡單 |
| D1／D7 保留 | 有回訪者完成未重複的對應能力題之正確率 | 同時報回訪比例與樣本數，缺席不可當答錯或滿分 |
| 遷移完成 | 新情境任務依規則／量表評定 | 與原句重做分開，查是否只背模板 |
| 習慣 | 有效學習日、週任務完成、主動回訪 | 不以停留時間與刷 XP 當學習提升 |

以上 60%、95% 是產品警示線，不是科學認證界線。資料未足時不作顯著性或效果大小宣稱。若未來要比較改版成效，需同等內容、相近起點、預先規劃樣本與對照，另設研究方案。

## 12. 第一批執行範圍與完成定義

第一批採「認識新朋友 → 介紹我和朋友 → 我的日常」3 單元，每單元引導、辨識／理解、獨立練習、情境挑戰共 4 節點；跨日複習由排程產生，不假裝已完成。

R1 的交付必須包含可機器讀取的 12 關資料、足量不同題面、答案與解析、先備、遷移題與內容審查紀錄。R2 必須能從選起點一路完成一關、看解析、補強、儲存、重新整理、接續及看到下一次複習。

在上述閉環與 R3 驗收前，不將 154 頁一鍵換皮為遊戲；在 R4 取得實際回訪資料前，不稱新版已提升學習成效。

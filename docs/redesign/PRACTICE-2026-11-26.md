# 2026-11-26 情境加練與閃卡訂正

讓各程度學習者依自己的步調先想、再核對和重試。活動設計參考外語字詞的提取練習與分散複習實驗。這次驗證涵蓋內容數量和操作行為，尚無學習者留存或延後測驗資料。[提取練習研究](https://doi.org/10.1126/science.1152408) · [分散複習研究](https://laplab.ucsd.edu/articles/Cepeda%20et%20al%202008_psychsci.pdf)

闖關分母合計 14,318 題，782 張加練約為 5.46%，最低單元為 5.0%。782 張包含 253 張答案訂正、176 張聽力、234 張字詞及 119 張閱讀證據。這些活動把原教材轉成回想或解釋練習，C1 → C2 的八張採另寫的新情境。各入口可能共用教學主題，活動以開口或心想後自行核對，不計 XP。

## 七輪規劃、執行與校正

| 輪次 | 規劃與修訂 | 實作及確效 |
| --- | --- | --- |
| 1. 內容基準 | 先區分單元核心題與舊有回想卡、片語及任務，再將改善目標落到每單元。 | 以現有去重函式建立分母，逐一驗算 141 個單元，另檢核所有教材分頁與精進課程。 |
| 2. 練習設計 | 從單一字彙填空擴成字詞、聽力、閱讀與選項訂正，以涵蓋初學和進階題庫。 | 各類輪替取樣，優先使用本單元和舊活動較少取用的來源，去除重複字詞目標。為精進課程另寫八個情境與示範。 |
| 3. 解說可靠性 | 先核對原選項、正解與題幹，再決定能否給明確的錯因。 | 依選項查找編輯解析，修復多選題把正解列為干擾項的問題，移除教材中的籠統時態歸因。 |
| 4. 先想再看 | 新卡需能單獨作答，聽力則保留文字替代。 | 顯示原題情境、待檢查答案及音訊控制，示範分開展開。檢查重複目標不被改成會露出答案的填空。 |
| 5. 閃卡訂正 | 首次作答、看解說、遮住重拼分成清楚的操作。 | 修正提示會清空輸入、空白送出便翻卡的情況，補上句中變化，重拼失敗時只提示差異位置。測試了鍵盤操作及複習紀錄。 |
| 6. 視覺與操作 | 檢查窄畫面、亮暗模式及鍵盤提示，優先處理對比與操作面積。 | 加練入口直接捲到練習並聚焦。調整閃卡主按鈕、小尺寸按鈕與鍵盤標記，依瀏覽器結果修正文字對比。 |
| 7. 發布校驗 | 以既有 Pages 流程發佈，先查清依賴、快取及兩份成品。 | 更新入口模組版本，核對成品檔案雜湊，執行網站測試、題庫稽核及音檔完整性驗證。 |

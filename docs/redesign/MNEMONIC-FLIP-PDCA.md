# 聯想字卡與 MP3 同步翻面｜2026-10-24

## Plan

基準 main：e1ddf18abf864664e75e0d4c7ddb8b14e26fdc86。此次限定聯想字卡，不包含工作區其他尚未完成的課程修訂。

一般模式正面只呈現題目（英文、發音提示、圖像符號），背面呈現中文、關鍵字、口訣、情境、拼字與例句。保留反向回想模式，其題目面先顯示中文；翻開後核對英文。播放任何 MP3 都提供固定可見的字卡，不受搜尋與分頁影響。

## Do

1. 教材核對：保留 v6 的 1,000 個穩定識別碼、口訣、音檔與使用者備份格式。
2. 正反面調整：翻開答案時隱藏題目面，加入大型圖像符號；保留原本兩個方向的複習紀錄。
3. 同步播放：從現有 audio-manifest.json 擷取 4,000 個片段時間，英文正面 → 口訣背面 → 中文背面 → 英文正面；不採平均分段。
4. 操作優化：固定播放字卡、暫停／續播、手動翻面、恢復自動及關閉停止。手動翻面不會被時間事件搶走。
5. 校正：切換播放器時重設手動狀態；停止時關閉隨聲字卡；暫停同步更新卡片播放按鈕。測試伺服器補上 MP3 Range 支援，避免將無法跳播誤判為翻面故障。
6. 回歸：320、390、1280 像素；實際音檔跳播、完整播放、自動換字、搜尋不中斷、缺失檔案重試及反向複習儲存。
7. 發布驗證：加入 CI 翻面與複習測試；只同步本次變更到 site/dist；部署成功後比對線上五份檔案雜湊。

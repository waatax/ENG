# C1→C2 精進課程：研究、規劃、執行與確效

## 接續上一輪

將原有四份進階作品任務接成有教學、形成性檢核、初稿、修訂與跨天複習的自學課程。保留原工坊與草稿，新增 `#advanced` 獨立入口，以小型模組載入，避免先下載舊教材與整套閃卡。

研究依據為 [Council of Europe CEFR 能力描述](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors)、[mediation 的說明](https://www.coe.int/en/web/common-european-framework-reference-languages/mediation)，以及 [Cambridge C2 教師手冊的作品評閱面向](https://www.cambridgeenglish.org/Images/168194-c2-proficiency-teachers-handbook.pdf)。依此選擇跨文本整合、讀者轉述、互動答辯、語域與細微語意等能力目標。教材及自評描述由本站撰寫，非官方試題或官方量尺複製。

## 8 單元與課程循環

| 單元 | 重點 | 作品與遷移 |
|---|---|---|
| 跨文本綜合摘要 | 共同點、分歧、來源限制 | 面向校長的整合摘要 |
| 論證、反駁與讓步 | 範圍、反方、處理機制 | 有條件的課程政策 |
| 同一訊息兩種語域 | 不變事實與對象需求 | 正式信與熟悉同事訊息 |
| 語氣與細微差異 | 保留、條件、反諷 | 精準改寫與口頭說明 |
| 聽取立場與限制 | 四欄筆記與轉折 | 兩段口頭報告摘要 |
| 專業內容轉述 | 白話、精確、決策需求 | 給學生會的研究說明 |
| 口頭答辯與修復 | 承接、澄清、回應 | 限定試辦的即席答辯 |
| 綜合提案與編修 | 指標、取捨、停止條件 | 280–340 字整合提案 |

每單元有兩段教學、三節點圖解、三列策略表、兩份情境來源、三步任務、四個具體檢查點、示範策略，以及兩組各三題不同的形成性檢核，共 48 題。選項順序洗牌，按原始選項索引評分；保留第一次回答，跳過不算答對。重練明示為同組題目，不發闖關 XP。

## 作品、排程與資料

- 草稿輸入後約 400ms 自動儲存在本機瀏覽器，離開時先完成待存內容；失敗時提示複製／下載。原四份草稿可帶入，原紀錄不被改寫。
- 初稿保留後不覆蓋。修訂稿須有不同文字、至少六字修改理由與四維自評；最多保留三份先前修訂。文字不同只是修訂流程檢查，不代表作品品質已達標。
- 四維為內容與證據、讀者與語氣、組織與連貫、語言與精準度，1–4 由學習者自評。英文詞數只提醒長度。可下載初稿、修訂、修改理由與自評為純文字，交給教師或同儕回饋；網站不替使用者傳送作品。
- 「學習循環完成」須讀教學、完成第一組檢核並留下初稿與有效修訂。徽章只表示流程證據，不換算 CEFR。
- 複習使用原有 1／3／7／14／30 天產品預設。提高間隔前須有修訂與最近一份第二組檢核至少 2/3；同一天重按不拉高間隔。「還要練」回隔天。
- 聽力使用裝置合成語音。只有完整播放且該組未開稿才列為未開逐字稿的聽力練習；開稿後再隱藏仍保留該組文字輔助紀錄。無可用語音時可切文字學習。沒有假造音素或口說程度分數。
- `eq_advanced_course_v1` 納入既有全站備份。寫作護照按專案 ID 合併新舊草稿，避免同一作品帶入後重複計數。保留原始遊戲、XP 與程度檢測資料。
- 首頁與側欄加入入口；旋轉／切換寬度時側欄依斷點展開或收合。

## 驗證與界線

新增測試涵蓋 8 單元／48 題內容、洗牌與評分、重複點擊／過期回應防護、作答接續、聲音與逐字稿分開記錄、初稿保護、修訂條件、歷史上限、間隔邊界、損壞存檔與儲存失敗、原草稿帶入、備份合併、HTML 逸出與各頁面渲染。GitHub Actions 加入新測試；完整發布檢查與正式站瀏覽器結果記錄於 `verification/advanced-course20261103/`。

這是有範圍的高階自學模組，不是完整 C2 認證課程或真人成效驗證。口說互動、自然語速真實音檔及獨立人工評閱仍需持續練習與外部回饋。依使用者要求，畫面與操作以 GitHub Pages 正式版本驗證，不開本機預覽。

# 2026-10-29 語音、訂正與全單元實用加練

## 目標與範圍

延續 English Quest 的分級路徑、XP、每日任務、金冠及間隔複習。讓初學者先觀察示範，熟悉者先回想並解釋，再把知識用在開口、情境與證據判讀。一般練習不增加生命限制，開放回答不偽裝成自動評分。

本次涵蓋 course registry 的 **141 個單元**，包括主線、目標分支及 12 個國高中學期單元。每個單元依關卡池中去重後的計分題數，增加 `ceil(原題數 × 0.1)` 張額外回想／運用卡，共 **1,483 張**。逐單元基準、數量與來源 ID 見 `verification/learn20261029/content.json`。

這是額外學習活動的 10% 擴充，不是增加 10% 的獨立新知、詞彙或計分題。每張卡取自該單元既有題目與解析，新增無選項回想、自我解釋、運用任務及檢核提醒。跨單元共享原教材的情況仍保留，總卡數不是全站獨立知識點數。獨立模考與考試遠征技能池未列為課程單元，不更動其固定試卷。

## 設計依據

[IES：Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) 建議間隔學習、示範與自行解題交替，以及以提取練習協助記憶。本次轉化為「自己想 → 聽與核對 → 換你運用 → 明天再想」。新卡使用既有題目答案作參考，口說和開放回答自評，不宣稱實證提升幅度；本次尚未進行真人學習成效研究。

## 實作與迭代

1. 盤點既有朗讀與回饋：原本已有題目與答案按鈕，本次補齊閱讀短文與每個選項的獨立朗讀。選項朗讀不會選取或提交答案。聽辨題的中文答案保留英文原音文字供跟讀；多選答案逐項朗讀。
2. 修正語音取消：使用者停止／換題時，即使裝置不送取消事件，也會結束等待中的 Promise；錄音失敗只啟動一次語音備援，舊回呼不會重新播放。
3. 訂正：同時顯示作答與正解、原題解析、下一步修正提示；解說朗讀包含錯答對照。配對錯誤立即說明兩個詞義，測驗模式維持不顯示正解。
4. 單元新增「加練」入口，直接前往指南中的任務卡。答案需自行展開；任務涵蓋詞語情境、聽後回應、規則解釋與文章證據。卡片不另發 XP，不以自評冒充精熟或正式程度。
5. 瀏覽器校正：新增選項朗讀區後，原測試把所有音訊控制算成答案控制；改為限定答案區並明確驗證測驗無答案／解析按鈕。新加入選項朗讀不提交、任務卡隱藏答案、四種寬度無溢出檢查。

## 驗證與限制

- 自動測試涵蓋所有單元最低增量、任務來源與解析、英中答案、多選、語音取消，以及原有進度、獎勵、檢測、學期、考試與模考。
- 瀏覽器驗證涵蓋手機與桌面（320／390／768／1280）、加練與答錯流程、舊進度接續及測驗不洩漏正解。
- **120 項自動測試、24 組瀏覽器流程全數通過**，題庫與既有音訊檢核亦通過。完整結果保存在 `verification/learn20261029/`。沿用 GitHub Pages 的既有發布檢查，新增學習任務測試作為上線門檻。
- 自動化瀏覽器可驗證語音呼叫和故障回饋，無法代表每個裝置的實際聲音品質。朗讀需要裝置提供中英文語音；不支援時顯示可理解的提示，畫面仍可閱讀與作答。
- 本次沒有逐題外部教師審定；後續優先做真人試用、獨立新情境題編寫與每級延遲回想評估。

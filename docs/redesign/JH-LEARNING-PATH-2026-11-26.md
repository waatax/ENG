# 國中英語六學期學習路線

入口是 [國中英語學習與考前練習](https://waatax.github.io/ENG/#jh/path)。學習者可從任一學期開始，也可先到全站做程度定位或補字母與生活英文。既有十六個主題、會考考點、生活案例與手冊一併保留。

## 兩本書如何落到學習流程

| 書中方法 | 平台實作 |
| --- | --- |
| 《Ultralearning》第 IV、VI、VII 章的後設規劃、直接學習與弱點練習 | 選擇學校進度、會考或 GEPT 初級。先用一項任務找線索，再回到相應學期的技能關或實際考卷。 |
| 《Ultralearning》第 VIII–X 章的提取、訂正和保留 | 先想再顯示選項。每個錯選都有理由和正解，訂正後暫隔 24 小時再做另一個情境。之後重練安排進間隔複習。 |
| 《Get Better at Anything》第 3、5、7 章的示範、難度調整與變化練習 | 需要支援時可先看例子，熟悉時直接作答。兩種情境保留同一個重點，改變人物、場地、文字或資訊條件。 |
| 《Get Better at Anything》第 9–12 章的明確回饋、真實使用、修正習慣和逐步接觸 | 讀出自己的錯因、重試、隔日換題，再到學期混合挑戰和官方題本。題後可另用英文開口或寫一句。 |

## 作答與考前紀錄

- 六學期十六個主題各有一組基本題與隔日變式，共 32 道原創題，含 6 道聽力與 2 道跨文本表格題，每項有開口或寫作提示。學期卡列出首次獨立變式答對數。文字輔助、首次答錯和熟題答對會呈現各自的紀錄。
- 會考分開記錄練習卷的閱讀和聽力。GEPT 初級加入官方題型入口、口說和便條寫作任務。可各自記錄練習卷的原始答對題數，近兩次結果供比較，搭配學期活動找補強方向。[國中教育會考](https://cap.rcpet.edu.tw/) · [GEPT 初級](https://www.gept.org.tw/Exam_intro/t01_introduction.asp)
- 聽力使用裝置朗讀。完整播放後才能開啟選項，也可主動開啟逐字稿，輔助紀錄會和獨立聽辨分開。進度及練習卷紀錄保存在本機，納入全站備份。
- 首次變式是技能取樣。口說與寫作供練習和人工回饋，正式成績與通過標準以主辦單位為準。此版驗證課程覆蓋、資料和操作，長期留存與實際考試表現需要後續觀察。

## 迭代校正

1. 盤點原來的十六主題、六學期、示範題與考試入口。原有小題組換算的國中就緒百分比改呈現實際示範題答對數。
2. 先做可自由切換的學期路線，再加上口說與寫作提示、跨日變式、讀表和音訊支援，逐一核對三個選項及其解析。
3. 將首次答題、文字輔助與熟題複習分開保存。用自動測試覆蓋提早提交、重複提交、備份還原與無法寫入的情況。
4. 用瀏覽器走過答錯到訂正、隔日狀態、聽力與逐字稿、聽讀練習卷紀錄和真實學期跳轉。依手機畫面收攏次要教材入口，保留鍵盤操作和 44px 觸控區。

## 執行與再校正

1. **先行動的首頁**：第一屏提供程度檢測、直接闖關及首頁暖身。四階段路線以能力目標導覽，完整三步課表與六力護照保留在後面。單字目錄改為展開後載入，首次首頁不必下載約 3.9 MB 的完整目錄。
2. **即時遊戲暖身**：4 種難度 × 3 題，涵蓋字詞、句型、情境、閱讀及論證。每題含正解、選項差異、例句、中文及新情境練習。「還不會」可先看教學，不增加星星。只記第一次回答；結果不改動正式程度、XP 或金冠。按本地日期、難度保留最近 28 筆結果，同日重玩更新當次證據而非製造最佳成績。
3. **圖解知識點**：4 組可切換觀念：第一個句子、時態、長句拆解、論證證據。每組都有結構圖、語意標籤、對照表、易錯提醒及先回想再揭答活動。圖示採程式原生 SVG，無額外圖片下載。
4. **一鍵真實闖關**：`quest/#quickstart` 對新使用者建立可修改的輕鬆／生活預設並直接開始第一課；回訪者保留既有設定，優先接續未完成作答。開課本身不發 XP。教材下載失敗不建立空殼課程。檢測與其他既有入口保留。
5. **進階作品出口**：`#masterclass` 新增 4 組原創引導任務：跨文摘要、論證與反駁、雙語域訊息、細膩語氣改寫與口頭答辯。每組含兩份來源／情境、三步鷹架、四項自評、可儲存草稿及示範策略。面向 C1→C2 延伸目標，明示這不是完整 C2 課程或程度認證，需教師／同儕評閱。英文詞數只作提醒，不當品質分數。
6. **介面**：暖白、森林綠、鼠尾草綠與低彩度金色；可操作文字搭配線條圖示。手機單欄、兩欄能力卡、局部可捲動表格；平板與桌機分欄。支援橫向、鍵盤焦點、減少動態、深色偏好與安全區。
7. **整合與部署**：新資料納入既有全站備份；修正首頁重複綁定事件；更新啟動及快取版本；同步 `dist/` 與 `site/dist/`。GitHub Actions 新增首頁／一鍵開課回歸。依使用者補充指示，畫面及操作以 GitHub Pages 正式站驗證，不使用本機預覽。

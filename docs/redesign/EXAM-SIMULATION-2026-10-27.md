# 擬真模考：研究、規劃與實作

日期：2026-10-27。入口：`dist/quest/simulation.html`，亦可從「考試遠征」及桌面側欄的「擬真模考」進入。第一輪整合本機 Project；第二輪完成發布前優化與驗證，透過 GitHub Pages 工作流程發布。實際部署狀態及線上檔案一致性以 `verification/simulation20261027/release.json` 為準。

## 問題與設計決策

既有考試遠征提供技能取樣與短卷，不能練習整節配速、到時鎖卷、跨節限制及延遲回饋。本次另建模考頁，保留原課程、遊戲進度與技能證據邏輯。模考不發 XP，也不把原始答對率轉成官方量尺分數。

以「題型介面、時間規則、返回與改答、題組結構、保存、交卷後回饋」六項作為實作與驗證面向。採固定卷先交付可實際操作的流程，適性演算法與真人等化研究不冒充已完成。

## 作答環境

1. 開始前顯示分節時間、題型、本站與官方差異；聽力卷提供英文語音音量測試。
2. 使用絕對截止時間，倒數不因重新整理、離頁或關頁重設。離頁跨過多節時，按原始時間逐節收卷，不補給新的一整節。
3. 每次改答、標記與寫作輸入都保存；作答項目與順序一同保存。分節過期後的點擊或輸入不接受，不能寫入下一節。
4. 聽力依固定節長分配題組播放區間，播放一次；同題組可切換問題，無法跳至其他音軌。下一組到時依序出現並嘗試播放。沒有逐字稿、慢速或重播。重載中斷的音訊會註記，不能偽裝成完整聽辨。
5. 學測與閱讀類題目提供標記、答題卡、上一題／下一題。GMAT 逐題確認、前進後暫時鎖定；完答才解鎖檢視，改選三次後不再接受變更。
6. 提供全螢幕切換。瀏覽器的全螢幕不是監考或安全考試瀏覽器；不攔截其他程式。離頁次數會出現在報告。
7. 提前交節會顯示未作答數並確認，下一節立刻開始。提前終止整卷會保留部分答案並標記未完成。
8. 全卷收卷後才顯示答案、解析與寫作評閱要點，可下載含題目、答案、時間與結果的 JSON 報告。新卷取代上一份本機紀錄前會提示先下載。

## 題庫與維護

- 七份固定卷，合計 428 個作答項目；跨考試可能共用素材，428 不代表不同原創題數。
- 新增作者來源共 137 個項目，包括新學測／英檢練習、圖片情境、應答、對話、GRE 特殊題型及 TOEIC 雙／三篇文件題。
- 其餘使用既有 `course/exams.json` 題庫。題型與選項數進一步整理；選項使用可重現的排列，避免正解全部落在首項。共用十詞／五句選項的順序跨空格保持一致。
- 建置檢查同卷題數、ID、題面重複、答案索引及解說。內容來源檔為 `data/exams/simulation-*.mjs`；以 `node scripts/build_simulation_bank.mjs` 重建，輸出至 `dist` 及 `site/dist`。
- 本機保存使用獨立的 `english-quest-simulation-v1`，不改寫遊戲存檔。

## 第二輪優化（simulation20261027r2）

- **部分作答判定**：多空題僅填一格、六選二僅選一項，以及只有空白的作文不計完整作答；黃色答題卡與交卷提示使用相同規則，輸入時即時更新並保留焦點。
- **存檔復原**：載入前檢查題目、答案型別、分節結果與原始截止時間；拒絕異常縮卷、擴時及不完整物件。異常原始資料保留供下載；另一分頁清除紀錄也能安全返回入口。
- **逾時邊界**：手動交節恰好超時時仍採原始節次時間，不會藉延後確認取得額外時間。入口頁等待到全卷到期時也會更新狀態。
- **聽力事件**：取消後的舊回呼不能改寫新播放狀態；播放完成不再關閉已開啟的交卷／終止確認框。TOEIC 應答選項納入音軌時間權重，GEPT 印在卷上的應答選項不額外朗讀。
- **操作與報告**：題型名稱改為中文；完整作答數即時顯示；GMAT 三次改答用完後停用其他選項；鍵盤選答保留焦點，換題移至題幹。
- **考後檢視**：可篩選需訂正、未完整作答、標記及人工評閱題；另顯示完整播放／中斷／未播音軌數，不把未完整播放的結果當作獨立聽辨證據。
- **更新相容**：更新 HTML、CSS、模組及題庫的請求版本，保留原存檔識別與固定卷版本；正常第一輪作答可接續。驗證只使用本輪相關檔案，其他未提交工作不納入發布。

## 真實程度與後續工作

已提供正式分項時長、題型操作及主要作答規則，仍不是官方等值模考：

- SAT／GRE／GMAT 尚未實作經校準的適性選題與官方計分；不預測正式分數。
- TOEIC／GEPT 使用裝置合成語音及線條示意圖，並非真人分角色錄音或照片。音軌依本站區間安排，語速、停頓、口音與素材長度不等同正式考場。正式全長語音、照片素材與逐題聽驗是後續內容工作。
- 題目難度與篇幅尚未經外部教師逐題審定或真人施測，不能聲稱與真卷等難；部分既有素材較短。
- GEPT 本輪明確限中級聽讀與寫作，尚無初級、中高級、高級、優級或口說模考。沒有把中級卷換個標題充當其他級數。
- 寫作與混合開放短答只提供參考方向及評閱要點，不用關鍵字命中或字數冒充語言品質評分。
- 一考試僅一份固定卷，重做不是未見卷。後續應新增經人工審稿、篇章隔離的 A／B 卷，再做配速與效度研究。

後續順序：教師審題與篇幅校正 → 真人音軌與照片 → 更多 GEPT 級數與口說 → 獨立新卷 → 真人配速與分數校準。完成前，各項限制繼續顯示在開始說明與考後報告。

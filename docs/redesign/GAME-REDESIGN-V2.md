# English Quest 闖關版 v2｜全站遊戲化大改版計畫（RPDCA）

日期：2026-10-23（Asia/Taipei）｜狀態：v2 的 R1–R5、Gemini 的 v3（第 1 段故事）與 v4（第 1–4 段 AI 逐題校審、長句排句）都已完成並通過驗證。第 5–9 段與分支尚未校審；沒有教師審定，也沒有真人試用。各輪結果見 [RPDCA-LOG](RPDCA-LOG.md)

前一輪 R0 完成研究盤點，並做出 3 單元、12 關、99 題的手寫試點（`dist/quest/`）。試點驗證了「短課＋即時回饋＋訂正＋跨日回想」可以運作，但只涵蓋零基礎三單元，其餘 151 個教材入口、154 篇會話與 2,000 題分層題庫都還在遊戲外。v2 把整個程度範圍都接入同一條 Duolingo 式的路徑。

## 4. 每個單元的節點

| 節點 | 內容 | 題型 |
| --- | --- | --- |
| 🔤 字詞 | 單元字彙＋同主題聯想字卡 | 看字選意思、聽音選字、中文選英文、配對、例句填空、聽寫 |
| 💬 會話 | 單元會話與章節片語 | 聽句選意思、選下一句、依中文排出英文句子 |
| 📐 觀念 | 概念卡＋例題、常見錯誤、知識點與圖解文法題、形成性測驗 | 先看重點卡，再作答；錯誤選項皆有解釋 |
| 🎯 精熟 | 對應的分層題庫子題型＋閱讀問答 | 單句選擇、短文閱讀 |
| 🏆 單元挑戰 | 從前四個節點重新混題 | 3 顆心；通過得金冠與寶箱，並排入跨日複習 |
| 📖 故事 | 每兩個單元之後一篇（程度相符時） | 逐句聽讀，途中插入理解題與接話題 |

11–20 個字的長句會話也有排句題：前半句給定，後半句（3–10 字）自己排，v4 新增。某類題目少於 4 題時就不單獨開節點，改併到相鄰節點，避免題量不足還硬湊出一關。一般課 8–12 步，答錯的題會在課尾再出一次（每題最多一次）。

## 5. 遊戲機制

| 機制 | 規則 | 防止失真 |
| --- | --- | --- |
| XP | 新課 10、全對 +5、故事 10、挑戰 20（未過 5）、跳級 30、到期複習 10；重練與練習區 5 | 以結算 session ID 去重，重新整理或重複送出不會重複給 XP；XP 只代表投入，不代表程度 |
| 每日目標 | 10／20／30／50 XP（輕鬆／一般／認真／衝刺） | 以使用者本地日期計算 |
| 連續天數 | 完成任一課、練習或故事即算一天 | 只開頁或播放不算 |
| 凍結卡 | 100 寶石換 1 張，最多持有 2 張；漏掉一天時自動使用，連續天數不中斷但不加 1 | 狀態清楚顯示，不誘導焦慮 |
| 寶石 | 每日任務 10、三項全完成再 +20、單元寶箱 15、成就 | 只能換凍結卡，不能換分數 |
| 每日任務 | 每天依日期固定抽 3 項（XP、完成課程、連對、聽力、訂正、故事） | 同一天所有裝置抽到的任務相同，可以重現與測試 |
| 連對 Combo | 連續答對 5／10 題有慶祝效果 | 只是回饋，不影響評分 |
| 愛心 | 只出現在單元挑戰與跳級測驗，3 顆用完時本次挑戰結束，可以立刻重試 | 一般課程沒有任何鎖定 |
| 成就 | 第一課、連續 3／7／30 天、完成第 1 段、5 篇故事、10 次全對、修好 20 題錯題、500／2000 XP | 名稱描述行為，不宣稱能力等級 |
| 跳級 | 每段都有「跳到這裡」；起步時可做 12 題分段測驗來建議起點 | 跳過的節點標為「已測過」，與「已完成」分開記錄 |

## 6. 練習與複習

- 錯題本：答錯的題目進入錯題本，之後在不同場次連續答對 2 次才移出。
- 到期複習：通過單元挑戰後依 1→3→7→14→30 天安排；到期答得好才延長間隔，答不好就回到 1 天。提前練習不會提前延長間隔。
- 個人化練習：從已學過的題目中，優先挑錯題、到期題，以及預估答對率接近 70% 的題目。
- 單字特訓：1,000 張聯想字卡依主題分組，聽真實 MP3 作答。
- 聽力特訓：只出聽力題；聲音無法播放時，可改成閱讀，但改讀的題目不計入聽力。

## 7. 介面

- 手機：上方狀態列（目前段落、🔥連續天數、💎寶石、⚡今日 XP），下方導覽（學習／練習／故事／教材／我的）。
- 桌面：左側導覽，中間是路徑，右側是今日目標環、每日任務、連續天數與凍結卡。
- 路徑：節點左右交錯排列；單元橫幅可打開「指南」；目前節點會跳動提示；鎖住的段落提供「跳到這裡」。
- 課程畫面：上方進度條與連對數（挑戰模式另有愛心）；下方檢查列答對變綠、答錯變紅並顯示解析。可用鍵盤 1–9 選答案、Enter 檢查／繼續；檢查前必須先選答案。
- 原創吉祥物「阿芽」（嫩芽造型的 SVG），不使用任何 Duolingo 角色或商標。
- 可關閉音效、減少動態效果、調整英文語音速度；顏色之外一律加上文字或圖示表示狀態。

## 8. 工程架構

```
scripts/build_quest_course.mjs   讀取現有模組 → 產生題目、品質過濾、套用校審決定、報告
data/quest-review/*.json         逐題校審的排除與修改（產生器套用，重建不會遺失）
dist/quest/course/index.json     段落、單元與節點結構（首頁只載入這個檔）
dist/quest/course/s1..s9.json    各段題目（進入該段才載入）
dist/quest/course/b-*.json       各目標分支題目
dist/quest/course/stories.json   互動故事
dist/quest/engine.mjs            純邏輯：組課、評分、XP、連續天數、任務、複習、遷移（不依賴 DOM）
dist/quest/sound.mjs             英文語音、單字 MP3 片段、WebAudio 音效
dist/quest/view.mjs、quest.css    畫面
```

紀錄存在 `english-quest-game-v2`。從 v1 遷移時，已完成的試點 12 關對應到新節點，原有 XP 與學習日都保留，**不刪除** v1 的資料。匯出與匯入使用同一個 JSON 檔。

### 題目品質閘門（建置時自動執行，不合格的題目直接排除並記錄）

- 選項不得重複，且答案必須在選項中；選擇題至少 2 個選項。
- 排句題：英文句子 3–10 個字，只含英文字母與撇號；干擾字不可出現在答案中；正確排序後必須能通過評分。
- 錯誤對照題：正誤兩句都必須是英文句子；中文說明性的陷阱只放在指南，不出成題目。
- 填空題：單字必須以完整單字的形式出現在例句中。
- 每題保留來源路由（`src`）；題目 ID 在不同版本間保持穩定。
- 某類題型不足時，就減少該節點，不重複出同一題來湊數。

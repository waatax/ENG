# 2026-11-03 回想、運用與語音體驗迭代

## 目標與現況

讓不同程度的學習者能從「看過／選得出來」走向「想得起來／用得出來」。保留既有闖關、XP、錯題訂正、題目／答案／解說朗讀與既有工作區升級，不重建另一套平台。

本輪診斷：舊閃卡掌握度主要靠手動標記；單元加練缺少複習安排；選項的朗讀控制巢狀在作答按鈕裡，鍵盤 Enter 又可能觸發送出；新增學習方式需要首頁入口與備份支援。

## 規劃與實作

1. **每日單字小遠征**：涵蓋原有八個字集共 9,500 張卡，每組最多十張，到期優先、其次未練。支援「中文說英文／英文想意思」兩方向，先回想再揭答，附詞義、搭配、雙語例句、題目與答案朗讀、慢速與停止。英文拼寫可輸入核對，指出第一處不同、缺字或多字；拼錯時必須選擇再練。中文理解及口說品質採自評，不假裝自動評分。
2. **全單元再增加至少 10% 運用任務**：141 單元，共 14,318 個單元內不同練習來源；各單元新增 `ceil(baseline × 10%)`，合計 1,483 張。新任務來源不與原有回想卡重疊，按詞義、聽力、閱讀證據、句構、輸入與排句調整活動。包含原題、示範答案、既有解說、朗讀與運用後自評。這是新的延伸活動，並非 1,483 道新原創計分題或新單字。
3. **間隔安排**：兩個單字回想方向與單元任務各自記錄。一般自評按 1／3／7／14／30 天安排；「還要練」回到隔天；首次「很熟悉」為三天。同一天重複操作不推升間隔。排程是產品預設，並非針對個人校準的記憶模型。
4. **視覺與操作**：暖白、森林綠與少量金色，統一圓角、留白、觸覺按鈕與清晰進度。手機採單欄自評、可橫向捲動字集，保留深色及減少動態偏好。回想中隱藏舊卡區，避免下方現成答案破壞回想；隨時可以結束小組回到完整閃卡。
5. **語音與鍵盤校正**：題目朗讀涵蓋完整題幹；選項發音改為獨立相鄰按鈕；Enter 在朗讀或其他按鈕上不會被全域提交攔截。保留單獨與整題選項朗讀、答錯的正解與原因解說。新回想輸入支援 Enter，避開中文組字期間。
6. **整合**：首頁與學單字頁加入入口；`eq_recall_v1` 納入全站備份／還原。新排程與原有掌握狀態、測驗分數和 XP 分開，儲存失敗會提示。更新入口與模組版本參數及 Service Worker 快取名稱。同步 `dist/`、`site/dist/`。

## 學習依據與界線

先提取再看答案、提供核對回饋、跨天複習，參考 [Carpenter、Pan 與 Butler（2022）綜述](https://www.nature.com/articles/s44159-022-00089-1) 與 [AERO 的間隔與提取練習指南](https://www.edresearch.edu.au/guides-resources/practice-guides/spacing-and-retrieval-practice-guide-full-publication)。這些研究支持設計方向，不等於本網站已有學習成效驗證。本輪也移除「念三遍記憶倍增」的無依據宣稱。保留初學者先看示範的路徑，以及熟悉者直接回想、解釋與換情境的路徑。

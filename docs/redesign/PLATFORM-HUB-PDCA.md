# 全站單字字卡與手機學習入口改版

日期：2026-10-24。起點：main 132da470fe4050a0d7dca70ba6d7e51e00d35bc2。

## 研究與規劃

原本入口散落在主站側欄、手機快捷列、MP3 播放列、聯想字卡、字族、遊戲及全英文學院。首頁需先閱讀大量介紹；分組 MP3 雖有時間標記，只有單字清單反白，離開清單後便看不到目前的字。

主導覽改為「首頁／學單字／玩遊戲／聽讀／教材」。遊戲及全英文學院保留自己的練習導覽，同時提供回主站與學單字入口。學習進度儲存格式不變。

設計依據：

- [W3C：Target Size](https://www.w3.org/WAI/WCAG21/Understanding/target-size)：主要觸控按鈕採至少 44 CSS px；這是本次設計目標，不宣稱整站已通過 WCAG 認證。
- [NN/g：手機導覽的可發現性](https://www.nngroup.com/articles/find-navigation-mobile-even-hamburger/)：常用入口直接呈現文字，避免把全部功能藏在選單裡。
- [NN/g：辨認與回想](https://www.nngroup.com/articles/recognition-and-recall/)：搜尋結果保留英文、中文及程度選擇，減少使用者記住分組編號的負擔。

圖片仍為教材既有圖像符號，不是新繪製的逐字插畫。沒有新增牽強諧音；有 v6 聯想教材的詞彙採用其口訣與校正例句，其餘保留既有提示或使用自行造句／遮答回想提示。

## 七輪迭代

1. **盤點與基準**：核對遠端與本機最新版本、列出各播放入口及時間資料；排除工作區其他未完成課程修訂。
2. **入口重整**：新增首頁雙入口、8 程度選單、英文／中文搜尋、可直達單字音訊位置的結果卡。保留舊網址。
3. **播放卡擴充**：建立穩定 ID 目錄；9,500 字三輪 MP3 與字族依時間表翻面；全英文語音依完成事件翻面。
4. **操作校正**：加入暫停、手動翻面、恢復同步、收合、關閉；修正暫停事件重新打開已關閉字卡；跳頁取消舊卡，過期回呼不能重啟播放。
5. **手機與效能**：移除首頁重複目錄與設定，固定五個常用入口；首頁不載入大型舊課程及閃卡程式。字卡目錄約 2.72 MB 未壓縮；沒有聲稱實測載入速度提升百分比。
6. **內容與回歸**：校正播放卡例句來源；測試 320／390／1280 px 主站及 320／390／768／1280 px 遊戲。修正主站／遊戲 `.shell` 同名樣式衝突；加入鍵盤焦點維持及不洩漏背面答案的字卡標籤。
7. **發布與比對**：同步本次檔案至 site/dist；CI 新增全詞庫與音訊邊界檢查；部署成功後比較 files.json 中各線上資產雜湊。

## 驗證與限制

- 66 項自動測試通過，涵蓋詞庫、連播、既有複習、英文學院及遊戲狀態。
- 全部 9,500 個卡片 ID、英文、中文、音檔組別及起始位置吻合；28,500 次英文／中文朗讀邊界通過。
- 主站 11 組瀏覽器檢查通過；遊戲 18 組流程通過，沒有 pageerror。
- 主站檢查包括搜尋、8 程度、跳播、翻面、暫停、關閉、字族、全英文卡、一般課程卡、目錄失敗重試與空搜尋。
- 真實 MP3 在 Edge 驗證；全英文合成語音以可控制完成事件的測試語音驗證序列，裝置實際語音品質及可用語音依瀏覽器而異。沒有假稱已在實體 iPhone／Android 測試。
- 尚未進行學習者長期成效研究；本次證據是內容配對、播放同步、介面與操作驗證。

記錄：`verification/platform-hub/browser.json`、`game/browser-v2.json`、`unit-tests.txt`；發布結果由 `scripts/verify_platform_release.mjs` 寫入 `release.json`。

## 後續維護

更新詞庫／MP3 後執行 `node scripts/build_vocabulary_catalog.mjs` 並重新同步發布鏡像。CI 會檢查卡片與音訊位置一致。新增播放入口應使用共用卡片元件，測驗題則保留答案隱藏規則。

# 播放模式與手機全螢幕｜2026-10-24

基準 ec20754，保留最新 v6 課程。單字 MP3 加入本組／本程度／全部隨機播放；每張卡在清單內只出現一次，沿用原音檔的三輪英文／中文及精確時間表。逐字切段跨組播放，暫停、續播、重試、下一張、停止均不修改答題進度。

錯題讀取目前瀏覽器的國小國中與完整單字練習（reviews > 0 且 step = 0）、閃卡 need_review、聯想卡任一方向尚未記住。依 ID 去重。不是歷史上曾答錯就永久加入；不宣稱包含文法與會話遊戲錯題。沒有可播放錯題會明確提示，儲存讀取失敗也會提示。聯想卡與字族頁另提供目前篩選結果的隨機與未熟悉清單。

# 國中、高中六學期：研究、規劃與迭代

## 研究與編排界線

依據[國家教育研究院發布的普通型英語文課綱](https://www.naer.edu.tw/upload/1/16/doc/812/(發布版)國民中小學暨普通型高級中等學校-語文領域-英語文課程綱要.pdf)，國中為第四學習階段、高中為第五學習階段；課綱以階段能力與學習內容訂目標，並非全國各版本完全相同的逐學期文法進度表。

本站因此採「依課綱目標設計的六學期自學順序」，而非官方統一分冊。高三下以加深加廣、自主學習與專題整合設計；普通高中高三上的必修與高三下的選修安排不混稱為六學期同樣的共同必修。技高職場、統測、國中會考與證照資料保留為依需求選用的延伸。

課程不只整理文法：每學期都有聽、說、讀、寫、綜合應用與學習態度的表現代碼，另列學習內容代碼，並依主題納入策略、文化或思考任務。代碼以既有官方條文資料逐項驗證；這是練習對照，不表示本站完整涵蓋每一條文或獲得課綱認證。

## 六學期設計

| 學期單元 | 國中 | 高中 |
| --- | --- | --- |
| 一年級上 | 我的校園與日常：句子骨架、校園指示、課表與介紹 | 句構、身份與觀點：複句、立場、段落支持細節 |
| 一年級下 | 社區生活與合作：活動、頻率、路線與邀請 | 文本、數據與媒體判讀：圖表、比例、推論強度 |
| 二年級上 | 經驗敘事與安排：時態、事件順序與條件 | 敘事視角與假設推演：反事實、敘事與證據 |
| 二年級下 | 選擇比較與感受：方案、限制、動詞語意 | 永續議題與論證限制：因果、替代解釋、研究摘要 |
| 三年級上 | 經驗、人物與公共參與：完成式、被動、指涉與服務 | 多文本綜合與論說表達：來源、反方與回應 |
| 三年級下 | 多文本閱讀與溝通整合：公告、表格、間接問句與事實意見 | 跨文化專題與自主學習：澄清、查核、回饋與修訂 |

每學期都有先備能力、四項可觀察目標、語言工具、教材順序、課綱表現與內容代碼、作品任務及四項自評規準。作品字數與口說時間是本站練習建議，不冒稱課綱規定。

## 實作

- 新增國中六個、高中六個學期單元，共十二條可自由選擇的學期路徑。
- 每學期五個節點：字詞句型、聽辨回應、閱讀推論、表達整合、學期精熟挑戰，共六十個新節點。
- 串接四十八個既有主題教材。主線使用原有教材 ID，既有進度與各主題歸屬不被新路徑覆寫。
- 新增七十二道原創計分題與十二張觀念提示卡，涵蓋情境文法、聽辨、雙題閱讀與排句。每個技能關固定包含本學期新題，再搭配該學期既有題庫；不會因隨機抽樣而完全跳過新增情境。
- 高三上核心不再使用國中會考或技高統測主題充作共同核心，高三下核心不再把 TOEIC／英檢證照當成所有人的共同進度。原教材仍保留於延伸入口與舊路線。
- 學習關約十題，學期挑戰十二題、三顆心，需至少 80% 獨立答對。聽辨題須取得完整播放證據；未播放或改文字不算獨立聽辨，不授予該次學期挑戰金冠。一般文字練習與自由選關仍可繼續。
- 一般學習沿用錯題、訂正、每日 XP 上限與間隔複習。課程來源尚未載入時不能只用少量新題啟動縮水挑戰。
- 作品區提供口說／寫作任務、可展開示範及朗讀、草稿與四項自評。草稿僅存在此瀏覽器，隨進度備份匯出；勾選不自動發 XP、金冠或斷言口說寫作品質。
- 新訪客可直接進入 `quest/#school`，既有使用者仍可從學習頁或「學期」導覽進入。重新整理保留已選學期，返回總覽時會保留對應學段。

## 迭代與校正紀錄

1. **盤點**：原有國中教材集中在兩段、高中按年級與考試混排，欠缺清楚的六學期入口與學期產出任務。
2. **第一版規劃**：保留原資料與進度，增加六加六學期容器、跨技能關卡、作品與課綱映射；避免直接重新編號造成紀錄失效。
3. **內容校正**：確認高三主線與延伸區界線；修正捐贈閱讀題的模糊選項，確保只有一個可支持答案；保留解說中的條件與因果限制。
4. **對照校正**：逐一驗證表現與內容代碼。把高三單一裝置語音的對照調整為說明理解，沒有宣稱已提供不同口音訓練。
5. **工程驗證**：檢查六十節點、固定新題、資料依賴、挑戰通過／失敗、舊進度、草稿跳脫、長度限制與備份。修正瀏覽器測試的下載路徑 API，用實際下載備份核對作品內容。
6. **第二輪優化**：補上高三返回總覽的學段保留、新訪客直達、聽辨證據與不完整資料阻擋。語音測試明確區分「自動播放已完成」與「完全未播放」，避免把已聽完的測試誤當成猜題。
7. **最終回歸與發布**：通過全站測試與實際瀏覽器操作後上傳，再核對 Pages workflow 及十七個線上核心檔案。

# 2026-10-26 遊戲化學習與語音訂正

## 目標與實作規劃

沿用現有 9 段程度、學習路徑、XP、連續天數、任務與金冠，讓學習循環變成「找起點 → 作答 → 理解錯誤 → 聽正解 → 慢速跟讀 → 再練習」。保留本機進度、錯題與間隔複習規則。

1. 入口：主站共用頂部新增固定可見的「檢測程度」，連到 `quest/#placement`；遊戲導覽與首次引導最上方也有按鈕。已有未完成練習時保留接續流程，不覆寫作答。
2. 題目朗讀：沿用題目與題幹的朗讀按鈕，混合文字逐段選擇中文或英文語音；朗讀不算聽力完成證據。
3. 正解朗讀：所有計分題作答後提供正常、慢速、停止控制，配對題逐組念英文與中文。排句保留前半句；填空在有句子時帶回完整句子。自動播放沿用個人設定，可關閉。
4. 錯題解說：保留題目原有 why，新增明確「為什麼？」與解說朗讀，依輸入、聽力、排句、配對提供訂正方向；跟讀內容同時呈現在畫面。
5. 手機校正：320px 起不橫向溢出；頂欄分兩排，回饋面板最多佔 48dvh 且可捲動，題目底部預留空間，避免長解析遮住題目；支援既有深色與減少動畫設定。
